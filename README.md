## 看板内容

1. **交易决策简报（V3 新增）**：每只 ETF 给出
   - 综合评分 **0–100**（趋势 30% × 估值 40% × 风险 30%；估值缺失时趋势/风险对半）
   - **数据完整度**（估值按官方 PE 积累条数计，趋势/风险按是否可用计）
   - **趋势状态**（MA20/MA60/MA120 + MA20 斜率 → 上升/下降/震荡）
   - **风险等级**（ATR(14)、ADX(14)、20日年化波动率、距60日高点回撤、距120日高点回撤 → 低/中/高）
   - **当前建议**（允许分批建仓/定投加档 · 持有为主等待回踩企稳 · 观望或按既定计划小额定投 · 高估但趋势尚在→持有观察/反弹分批止盈 · 暂停新增仓位优先控制风险）
   - **主要判断依据**（三维各自结论与关键数值）
   - **分批执行纪律**（第一笔 40% → 第二笔 30% → 第三笔 30%，含触发条件；趋势下降/风险过高时暂停新增）
   - **ATR 参考价位**（参考波动区间 + 跌破/突破观察位，非止损指令、非保证成交价）
   - **基准仓位与配置上限**（沿用各品种 base/max/min）
2. **宏观环境**：利率环境（中国10Y国债收益率 + 较20日前变化bp）、政策风向（LPR 1Y/5Y + 手动维护条目）、市场情绪（两市成交额 + 较20日均量比），每日自动更新
3. **创业板红利比**：创业板指(399006) ÷ 中证红利(000922) 归一化相对强弱，近3年历史分位解释（不据此单独交易）
4. **单只ETF卡片**：最新价、涨跌幅、PE + 三档滚动分位（近1年/近3年/近5年，估算口径展示）、分位样本数、股息率、RSI、MA20/MA60、趋势/风险、ATR 参考区间、做T支撑/压力位（**分列展示**；MA20 按当前价在其上/下互斥归属，避免同价位双标）
5. **买卖信号（明细）**：估值/RSI/布林/均线/偏离 逐项 chips + 信号标签（估值项采用近3年分位；RSI 为 Wilder 平滑口径，阈值 rsi_low=35 / rsi_high=70）
6. **定投建议**：按**官方 PE 分位**分档（双倍 / 正常 / 减半 / 暂停）；官方积累不足时"数据积累中，先按正常定投"
7. **价格走势图**：近250日收盘 + MA20/MA60 + 布林带
8. **估值分位走势图**：PE分位·近3年滚动窗口（750交易日）逐点折线
9. **长期操作纪律**：基准仓位、再平衡规则、风险提示

## 回测用法

```bash
python backtest.py output/price_history_515180.csv        # 红利
python backtest.py output/price_history_516310.csv        # 银行
python backtest.py output/price_history_515220.csv        # 煤炭
python backtest.py <任意csv> --fee 0.001 --slippage 0.001  # 可调费滑
```

> 回测为**基准测试策略**（MA 多头排列、信号次一交易日生效、含单边手续费+滑点 0.2%），用于检查趋势规则是否合理，不代表 V3 决策信号已获历史收益验证。当前真实数据结果（2026-11 本地积累）：
> 红利 策略 -4.6%/年 vs 持有 +4.8%；银行 策略 +0.8%/年 vs 持有 +7.6%；煤炭 策略 -9.6%/年 vs 持有 +3.2%（高股息/低波标的下简单 MA 趋势过滤跑输持有属常见现象，仅供规则研究）。

## V3 决策口径（重要）

- **估值严格化**：V3 只用**积累库中证官方 PE 观测**计算历史分位并参与决策，**≥200 条有效记录**才计算；样本不足时估值维度明确标注"数据不足"、**不参与综合评分**，看板显示"暂不判断"，绝不把价格回推得到的估算 PE 冒充真实历史估值。看板卡片上的三档分位仍为估算口径展示（已标注），但不参与决策。
  - **官方 PE 口径（2026-11-02 起）**：积累库统一采用中证官网估值图接口 `indexCsiDsPe` 的 `peg` 字段（官网"指数估值"图表数据源，日频全历史）；与官网 XLS 文件中的"市盈率1/市盈率2"存在口径差（股本/算法不同，同日均属官方发布值），迁移时按 date+index_code 去重覆盖旧值，分位计算全部基于新口径，历史贯通
- **风险压制买入**：长期趋势下降或风险过高时，不再因 RSI 超卖 / PE 低估直接给出"强烈买入"——最高只给"观望或按既定计划小额定投"，或"暂停新增仓位，优先控制风险"。
- **分批建仓纪律**（趋势风险允许时）：第一笔 **40%**（趋势条件仍成立）→ 第二笔 **30%**（回踩 MA20 附近重新站稳）→ 第三笔 **30%**（突破近 20 日高点 + 成交确认）。趋势下降/风险高 → 暂停新增主动仓位；估值高估 → 暂缓新增。
- **ATR 参考价位**：参考波动区间 = 现价 ± ATR(14)；跌破 现价-1.5×ATR 关注企稳、突破 现价+1.5×ATR 关注趋势确认。为观察条件，**非自动止损指令、非保证成交价**。

## 数据源与说明

- **行情（自动回退链）**：东方财富（前复权，本机优先）→ 腾讯（当日、海外可访问）→ 新浪（T-1 兜底）。GitHub Actions 海外环境访问东财会被拒绝/限流，自动切腾讯，数据仍为当日
- **估值**：中证指数官网**估值图 JSON 接口优先**（`/csindex-home/perf/indexCsiDsPe`，全历史日频官方 PE，一次拉取指数上市以来全部记录），失败回退官网 XLS 静态文件（近约20期）。积累库由该接口全历史自动覆盖，三个标的均立即超过 200 条门槛（000922/000820 ≈ 3800 条、399986 ≈ 2900 条），估值维度即日起参与决策；每日运行自动增量同步最新交易日。接口不可达时沿用仓库积累库（徽章变黄提示），次日重试
- **股息率**：中证官网 XLS 静态文件近约20期「股息率1」官方口径，`patch_dy` 只填充积累库已有日期行的 dy 字段（不插入新行、不覆盖 pe/pb）；接口不可达时看板显示 `--`
- **PE 分位（日频估算口径，仅展示）**：以官方最新 PE 为锚，用**指数日线点位**（000922/399986/000820，真实点位、无复权问题）按比例回推近 5 年日频 PE 序列（假设 EPS 近似恒定）；积累库官方全历史覆盖后，窗口内绝大多数日期为官方真值；窗口样本不足 80% 显示"积累中"；主信号取近3年档
- **宏观指标**：利率=中国10Y国债收益率（英为财情 `bond_zh_us_rate`，较20日前变化bp，<2.0% 宽松 / >2.8% 偏紧）；政策=LPR（央行 `macro_china_lpr`）＋ `MACRO_POLICY` 手动维护条目；情绪=两市成交额（腾讯指数日线 amount 求和，口径为千元，较20日均量 >1.2 放量 / <0.8 缩量）。任一数据源失败仅该格显示 --，不影响主流程
- 本工具仅作数据监测与量化参考，**不构成投资建议**；市场有风险，投资需谨慎

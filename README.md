# ETF 智能监测工具（单窗口看板）

监测 **红利 515180 / 银行 516310 / 煤炭 515220 / 自由现金流 159201 / 红利低波 563020** 五只 ETF，一个浏览器页面看完全部指标，每只标的配有针对性的专属监测维度。

## 云端看板（手机/电脑随时看，无需开电脑）

**看板网址：https://xhxie123-maker.github.io/etf-monitor-V3/output/etf_dashboard.html**

- 由 GitHub Actions 每个工作日 15:35（北京时间）自动更新，更新后自动发布到该网址
- 手机、轻薄本打开网址即看全部指标
- 仓库 Actions 页可手动点「Run workflow」立即更新
- 估值分位历史随仓库持久化（`output/valuation_history.csv`），每日自动 +1 期

## 本地快速开始

- **自动运行**：已配置 Windows 计划任务「ETF每日监测」，每个工作日 15:30 收盘后自动更新看板
- **手动更新**：双击 `run_monitor.bat`，更新后自动打开浏览器
- **查看看板**：打开 `output\etf_dashboard.html`（双击即可，无需联网，ECharts 为本地文件）

## 看板内容

1. **创业板红利比**：创业板指(399006) ÷ 中证红利(000922) 的归一化相对强弱（各自相对基期涨幅之比，基期随数据源起点变动但分位不受影响），近3年历史分位 + 风格轮动建议；**该比值只反映相对走势强弱，不代表估值便宜度**
2. **单只ETF卡片**：最新价、涨跌幅、PE/PE分位、股息率、RSI、MA20/MA60、偏离20日线、ATR参考区间、做T支撑/压力位
3. **专属监测指标**（每只标的不同）：
   - 红利ETF：股息率-10Y国债利差、股息覆盖（官网XLS近20期口径）
   - 银行ETF：股息率-10Y国债利差、PB 估值分位（无官方历史接口时如实标注）
   - 煤炭ETF：股息率-10Y国债利差、焦煤主力期货月/季趋势
   - 自由现金流ETF：价格结构（最大回撤、距上市高点、近20日新高天数）
   - 红利低波ETF：股息率-10Y国债利差、低波属性（年化波动率 vs 中证红利）、相对红利超额（250日）
4. **买卖信号**：综合评分制（估值+RSI+布林+均线+偏离），输出 强烈分批买入 / 逢低分批买入 / 观望持有 / 逢高减仓
5. **定投建议**：按PE分位分档（双倍 / 正常 / 减半 / 暂停）
6. **价格走势图**：近250日收盘 + MA20/MA60 + 布林带
7. **估值分位走势图**：PE历史百分位（本地积累库 / 中证官网官方积累）
8. **组合相关性矩阵**：近250个交易日日收益两两相关系数（红利低波×银行、红利低波×红利相关度高属红利家族预期）
9. **长期操作纪律**：基准仓位、红利家族合计上限、再平衡规则、风险提示

## 数据源与说明

- **行情**：东方财富（akshare 接口）优先，失败自动切新浪/腾讯；指数日线中证系（000922/399986/000820/H30269）优先中证官网官方通道
- **估值**：中证指数官网（官方 PE/股息率 XLS），每日积累历史样本；H30269 官方 PE 积累自 2013-12 起全历史
- **分位说明**：PE分位基于本地积累样本，首期约20期、每日自动增加；创业板红利比分位基于近3年价格，从第一天起即可用
- **样本说明**：红利低波ETF（563020）2023-12 上市，价格样本约3年（指数官方全历史已接入，估值分位完整）；自由现金流ETF（159201）价格样本为上市以来客观上限，官方 PE 未公开接入
- 本工具仅作数据监测与量化参考，**不构成投资建议**；市场有风险，投资需谨慎

## 修改信号阈值

编辑 `etf_monitor.py` 顶部 `TH` 字典中的参数即可（如 `pe_low`/`pe_high`/`rsi_low` 等），保存后重跑脚本生效。

## 故障排查

- 无更新：检查计划任务状态（任务计划程序 → ETF每日监测 → 运行状态），或看 `run_log.txt`
- 看板显示"积累中"：当日估值接口暂不可用，次日会自动重试
- 依赖问题：确保 Python 环境可 `import akshare, pandas, numpy, requests`（工具使用 `D:\APP\Python\python.exe`）
